# pi-compact 开发与真实压缩比较报告

本项目要让普通 Pi 插件提供百分比压缩、Codex 远端检查点、可恢复的原生回退和简洁的完成界面，并用实际业务任务比较远端与 Pi 原生压缩的效果。

**当前结论：本地产品实现与视觉审阅已完成；真实验收未通过。没有证据证明 Codex 远端压缩优于 Pi 原生压缩，也没有证据证明它无效。** 本次真实实验在兼容性阶段停止，未形成有效质量样本。

### 本次真实运行暴露的停止缺陷

首个 `NON_SSE_RESPONSE` 已写为失败，但未设置 `auditFailure`。旧执行器只检查特定审计码，因此又发送了第二个探测请求。第二个 HTTP 400 才触发全局停止。这偏离了首个不可审计响应即停止的约束，不能用“总预算未超”掩盖。

修复将所有已失败的 dispatch 都作为持久的全局停止条件，同时使剩余 lane 标记为不可执行。只改比较执行器的两个判断；安装包产品代码不变。

修复前后同一离线反例验证：非 SSE、缺 Content-Type、损坏 SSE 和发送异常，修复前均可发送第二个请求，修复后均在第二次 send 前拒绝。另验证缺终态、HTTP 拒绝和正常 SSE。7 项检查包括关闭和重新打开账本，证明停止状态不会因重启消失。实际 Pi 宿主注入非 SSE 后只有 1 次模拟 dispatch；正常兼容性流程的 8 次模拟 dispatch 通过。原三组比较修复回归、lint、typecheck 通过。

首次本轮 lint 发现旧验证脚本的 13 个未使用导入，已删除后复跑通过。本轮没有重新运行完整 248 次模拟矩阵、全部产品单测或性能测试，历史证据不冒称本轮新测量。

停止修复的 fresh 独立核验已通过，绑定 `27d84826414b5a6f7d994ee31db2d457d25ab97e`。独立复审覆盖 14 类传输探针、异常退出恢复、五组实际宿主测试及恢复重跑。13 类异常均阻断第二次发送，正常流程不误阻断；新增真实请求为 0。报告见 `artifacts/P6-real-stop-acceptance/REPORT.md`。本轮已停止一切剩余真实工作。修复改变了冻结 runner 绑定，现有真实 grant 不可用于新代码；旧冻结文件与原始失败记录保留，不重置预算、不自动重跑。

## 3. Data

用户批准了最多 260 次请求，其中比较 248 次、功能验收 12 次。真实运行使用批准的 Terra 原生和远端探测，输出 cap 均为 1,000，reasoning 为 none，SSE，零自动重试。

| 实际顺序 | 模型 / 压缩臂 | 观测结果 | 可用质量样本 |
| --- | --- | --- | --- |
| 1 | gpt-6.1-terra / Pi 原生 | 成功 HTTP 类别的响应未满足 SSE Content-Type；记录 `NON_SSE_RESPONSE` | 无 |
| 2 | gpt-6.1-terra / Codex 远端 | HTTP 400，记录 `HTTP_REJECTED` | 无 |
| 后续 | Luna 两臂、40 个正式比较 lane、Sol/DeepSeek 功能验收 | 全部未执行 | 无 |

| 计数 | 实际值 |
| --- | ---: |
| 真实请求预约 / 已收到 HTTP 响应 | 2 / 2 |
| 完成压缩续接的请求 | 0 |
| 有效成对质量样本 | 0 |
| 未使用且不继续执行的请求额度 | 258 |
| 输入预算估算已预约 | 63,737 |
| 输出预算已预约 | 2,000 |
| 服务端实际 token、费用、质量差值、压缩率 | 未知，不计算 |

63,737 是两次解码 HTTP 请求体字节数分别除以 4 后向上取整的总和，是本地预算代理量，不是服务端输入 token。2,000 是输出预留，不是实际生成量。2 次响应确认只证明拿到了 HTTP 响应，不证明模型成功执行或用量得到核验。

首个响应的正文和精确 HTTP 状态未保存；第二个响应只保留 HTTP 400，没有错误正文。因此不能断言服务拒绝了输出 cap，也不能断言账号不支持 Terra。没有进行取消 cap、换模型、修改请求或额外重试来猜测原因。

原计划使用 Terra/Luna、两个文件修改任务、每格五对 AB/BA 对照，固定历史切分、工具编码、reasoning off 和输出 cap。评分包括事实、未完成任务、文件状态、实际业务回归和保护文件。本次所有正式比较均未执行，不能绘制质量胜率或宣称压缩比例下降。Pi 对照是原生摘要流程，在双方共同约束下运行，并非“完全不调用模型的本地算法”。

**“没有优势证据”是本次数据的结论；“远端无优势”或“远端无效”不是。** 若要形成质量结论，必须先在保持可审计预算的前提下解决响应兼容性，再获得真实压缩及续接样本。本轮没有继续此类诊断请求。

### 证据与清理

本目录 `summary.json`、`requests.json`、`cleanup.json` 为公开白名单摘要，`raw-evidence-hashes.json` 绑定原始记录。原始运行目录为 `artifacts/P6-real/runs/20261117-full-comparison`，保持私有，不发布凭据、真实授权文件或 opaque 数据。真实运行读了既有 Pi 凭据文件，仅向运行时提供 Codex 凭据；没有复制或刷新凭据，没有读取真实会话历史。

真实运行的 3 个登记 PID 全部退出，监听端口和 tracked socket 为 0。停止修复的实际宿主故障与正常探测也已清理。Prove It Works 要求以实际请求和文件证明行为；Fix Root Causes 使停止判断覆盖真实失败状态，而非继续追加错误码名单。
